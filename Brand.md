afeTrace Color System

The colors below are defined as design tokens and should be used consistently across the Android App, React Dashboard, Landing Pages, Presentations, and Marketing Materials.

Token	Color Code	Usage
--color-primary	#6B4F3A	Primary brand brown, navigation, headers, logo, primary buttons
--color-primary-hover	#5A4230	Hover states for primary buttons and links
--color-primary-light	#8A6A51	Secondary brand accents and highlights
--color-surface	#FFFFFF	Cards, backgrounds, containers
--color-background	#F8F8F6	Application background
--color-danger	#D92D20	SOS, emergency alerts, danger notifications
--color-danger-light	#FEF3F2	Danger card backgrounds
--color-safe	#2E7D32	Safe states, successful check-ins
--color-safe-light	#EAF7EC	Safe status backgrounds
--color-warning	#F59E0B	Suspicious activity, caution states
--color-warning-light	#FFF7E6	Warning backgrounds
--color-text-primary	#1D1D1D	Main text
--color-text-secondary	#5F6368	Secondary text
--color-border	#E5E7EB	Borders, dividers
--color-disabled	#BDBDBD	Disabled controls
--color-map-route	#6B4F3A	Route tracking on maps
--color-map-user	#2E7D32	Current user location marker
--color-map-alert	#D92D20	Danger zone markers
